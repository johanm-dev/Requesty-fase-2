REQUESTY - Sistema Web con Arquitectura MVC en PHP
===================================================

Este proyecto ha sido completamente migrado a una arquitectura MVC en PHP:

1. Punto de entrada:
   Abre en tu navegador (con Apache activo en XAMPP):
   http://localhost/Requesty%20-%20BETA%20v_0.2%20UPDATE/
   o bien:
   http://localhost/Requesty%20-%20BETA%20v_0.2%20UPDATE/index.php

2. Estructura de carpetas MVC:
   - app/config: Configuración y conexión PDO a base de datos.
   - app/core: Núcleo (App, Router, Controller, Model).
   - app/models: Modelos de datos (Usuario, Pedido, Producto, Mesa, Caja, Pqrs).
   - app/controllers: Controladores para cada módulo y API AJAX.
   - app/views: Vistas PHP y layouts reutilizables (header, sidebar, topbar, footer).
   - database: Script SQL completo listo para phpMyAdmin (requesty_database.sql).
